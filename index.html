      Connect GitHub to edit

      Anyone can view this board. To add or change tasks, connect your GitHub account once on this device. Every change is saved as a commit in the team repository, so the board and its full history live on GitHub.

      1. Accept the collaborator invitation to the repository (sent by its owner).
      2. Open GitHub → New personal access token (classic). The public_repo scope is pre-selected; set the expiration to the end of the project.
      3. Select Generate token, copy it, and paste it below.

      The token is stored only in this browser and is sent only to api.github.com.
